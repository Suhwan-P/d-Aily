# 왜무새 파티 — 진짜 이유를 찾아라

d-Aily 왜무새 멀티 데모. 왜무새의 "왜?" 질문에 그럴듯한 **가짜 이유**를 쓰고,
진짜 이유 + 모두의 거짓말 + 왜무새의 거짓말 사이에서 **진짜**를 골라내는 Fibbage식 파티 게임.

## 한 판 흐름
로비(방 코드/링크) → 쓰기(45초) → 고르기(25초) → 공개(속은 사람 → 마지막에 진짜) → 라운드 순위 → … → 최종(간파왕·거짓말왕·웃음 제조기·오늘의 명대사)

- 점수: 진짜를 맞히면 **간파 +1000**, 내 거짓말에 한 명 속을 때마다 **속임 +500**, 마지막 라운드 2배
- 진짜 이유와 너무 비슷한 답은 거절, 같은 거짓말은 합쳐서 함께 점수
- 폰이 잠들거나 새로고침해도 같은 자리로 복귀 (토큰은 localStorage)
- 방장은 봇 추가 가능 → 인원이 적어도 시연 가능
- 정답은 `shared/questions.ts`의 **검증된 문제 은행(30문항)** 에서만 나옴. AI는 정답을 만들지 않음
- 문제는 "아무도 모를 법하고, 진짜가 더 황당한" 것 위주 → 다 같이 지어내는 게임
- 💡 거짓말 추천받기: 막히면 그럴듯한 가짜를 받아 고쳐 쓸 수 있음 (라운드당 2번)

## 구조
```
shared/engine.ts     게임 상태 머신 (서버·혼자 해보기 공용)
shared/questions.ts  문제 은행 — 질문/진짜 이유/설명/가짜 이유
server/index.ts      Express(정적 파일) + Socket.IO(방, 재접속) + 선택: Claude 가짜 이유
src/                 React 화면 (홈·로비·쓰기·고르기·공개·결과·최종)
scripts/test-multi.ts 3명 접속 → 3라운드 끝까지 자동 플레이 테스트
```

## 로컬 실행
```bash
npm install
npm run dev          # 서버 :3000 + 화면 :5173 (같은 와이파이 폰은 http://<내IP>:5173)
npm run build && npm start   # 배포와 같은 방식, http://localhost:3000
npm test             # 서버 켠 상태에서 멀티 자동 테스트 (URL=http://localhost:3000)
```

## 무료 배포 (Render Free)
1. 이 폴더를 GitHub 저장소로 올린다.
2. Render → **New → Blueprint** → 저장소 선택 (`render.yaml`이 설정을 채움)
   - 직접 만들 땐: Web Service / Build `npm ci --include=dev && npm run build` / Start `npm start` / Plan Free
3. 선택: 환경 변수 `ANTHROPIC_API_KEY` → 왜무새 가짜 이유를 Claude(Haiku)가 매 라운드 새로 씀. 없으면 문제 은행 가짜 사용
4. 나온 주소(`https://wae-party.onrender.com` 등)를 친구들에게 공유

주의: Free는 15분 동안 접속이 없으면 잠들고, 깨어나는 데 약 1분 걸림 → **발표 5분 전에 한 번 열어 깨워 두기**.
방은 서버 메모리에 있어서 서버가 잠들면 사라짐(데모엔 충분). Vercel은 웹소켓 서버를 오래 띄울 수 없어 이 게임엔 맞지 않음.

## 문제 추가
`shared/questions.ts`에 항목을 추가. 원칙: ① 대부분 모를 법한 질문 ② 진짜가 오히려 거짓말처럼 들리는 것 ③ 정답은 출처로 확인된 것만(학설이 갈리면 제외) ④ 진짜 이유 40자 이내 ⑤ 가짜 이유 5개.
